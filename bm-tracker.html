    云端同步
    把记录同步到你自己的免费 Supabase 项目,换手机、丢手机、清空浏览器也不怕数据丢失。数据只发送到你自己配置的地址,不经过任何第三方服务器。怎么设置?
    3 步开启云端同步(免费,约2分钟):
    1. 打开 supabase.com,免费注册并新建一个项目(New Project)。
    2. 项目建好后,进入左侧「SQL Editor」,粘贴下面的建表语句并运行一次:
    create table records (
  id text primary key,
  user_id uuid not null default auth.uid() references auth.users(id),
  ts bigint not null,
  duration bigint,
  bristol int,
  amount text, color text, smell text, feel text,
  symptoms jsonb, mood text, place text, note text,
  updated_at bigint not null
);
alter table records enable row level security;
create policy "owner access" on records for all
  using (auth.uid() = user_id) with check (auth.uid() = user_id);
    1. 进入「Project Settings → API」,把 Project URL 和 anon public key 复制粘贴到下面。
    Supabase 项目 URL Supabase anon public key
